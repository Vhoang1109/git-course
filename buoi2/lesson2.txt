1. Giải thích câu lệnh: git init, git add <file_name>, git add ., git commit -m "message"
---
git init: Khởi tạo 1 local repository
git add <file_name>: thêm file_name vào vùng staging area
git add . : thêm tất cả các file ở working directory vào vùng staging
git commit -m "message" : commit tất cả các file ở staging area lên local repository với "message"
---
